# PsychoPy_SentenceRating_Practice

PsychoPy 句子评分任务练习材料：中文教程、16 个试次的 CSV 条件表和两款中文字体。

## 开始练习

1. [在线阅读完整教程](Tutorial/PsychoPy_SentenceRating_Practice.md)。
2. [下载完整练习包（ZIP）](https://github.com/zqzhao-sudo/Psychopy_SentenceRating_Practice/releases/download/v1.0/Psychopy_SentenceRating_Practice.zip)，然后解压。
3. 按教程安装 PsychoPy、配置条件表和字体，在 Builder 中搭建实验。

本仓库提供教程与材料，教程代码中的组件名等占位内容需按你的项目填写。
